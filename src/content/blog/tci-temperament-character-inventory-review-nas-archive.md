<p class="sk-p" style="margin: 0 0 20px; font-size: 1.03rem;">요즘 방송과 강연에서 가장 화제가 되는 상담가를 꼽으라면 단연 이호선 교수다. 이호선 상담가가 내담자와 본격적인 대화를 나누기 전에 반드시 거치는 관문이 하나 있는데, 바로 <mark style="background: linear-gradient(120deg, rgba(204, 227, 222, 0.55) 0%, rgba(204, 227, 222, 0.95) 100%); padding: 2px 6px; border-radius: 4px; color: inherit; font-weight: 600;">TCI(기질 및 성격 검사)</mark>다. 얼마 전 아내는 나에게도 이 검사를 꼭 받아보길 권했다. 객관적인 지표로 나를 설명해 주는 결과지를 마주해야, 비로소 내가 왜 이런 선택과 반응을 반복하는지 확실히 알 수 있을 것 같다는 이유에서였다.</p>
<p class="sk-p" style="margin: 0 0 20px; font-size: 1.03rem;">사실 나는 4년 전에 이미 이 검사를 받아본 적이 있다. 이전 직장에서 근무하던 시절, 상담 선생님의 권유로 문항을 채웠던 기억이 희미하게 남아 있었다. 당시 선생님이 결과지를 펼쳐놓고 무언가 열심히 설명해 주셨는데, 정작 머릿속에 남은 내용은 전무했다. 아내가 다시 TCI 이야기를 꺼내고 나서야, 그때 받았던 종이 한 장의 행방이 궁금해졌다.</p>
<p class="sk-p" style="margin: 0 0 20px; font-size: 1.03rem;">평소 어떤 종이 문서든 스캔해서 디지털 아카이브로 남겨두는 습관이 있다. 분명 어딘가에 보관해 두었을 터였다. 하지만 집에서 운영 중인 시놀로지 나스(Synology NAS)의 저장 공간을 아무리 샅샅이 뒤져도 'TCI'나 '심리검사' 같은 이름의 파일은 코빼기도 보이지 않았다. 설마 그때만큼은 스캔을 건너뛴 걸까 싶어 의아해하며 며칠을 흘려보냈다.</p>
<p class="sk-p" style="margin: 0 0 20px; font-size: 1.03rem;">유독 업무에 집중이 안 되던 어느 오후, 작정하고 오래된 스캔 폴더를 하나씩 열어보기 시작했다. 그리고 전혀 예상치 못한 구석에서 그 결과지를 찾아냈다. 검색으로 찾을 수 없었던 건 너무나 당연했다. 파일 이름이 <span style="font-family: ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace; font-size: 0.92rem; background: #f2f7f6; color: #0f766e; padding: 2px 7px; border-radius: 5px; border: 1px solid #cce3de; font-weight: 600;">S28BW-823020117000.tif</span>라는 낯선 기계식 코드로 저장되어 있었기 때문이다. 스캔만 해두고 파일명을 고쳐 놓지 않았으니 검색창이 알아볼 리 만무했다. 그 와중에 피식 웃음이 났던 건, 역시나 내가 4년 전에도 성실하게 스캔 버튼만큼은 눌러뒀다는 사실이었다.</p>
<p class="sk-p" style="margin: 0 0 24px; font-size: 1.03rem;">그렇게 발굴한 파일을 곧장 아내에게 전송했다. 4년 전 종이 위에 찍힌 그래프와 숫자들은 소름이 돋을 만큼 지금의 나를 그대로 설명하고 있었다. 조금 더 객관적이고 냉철한 시선으로 이 수치를 읽어내기 위해, 평소 나의 삶의 궤적과 기록들을 잘 알고 있는 AI '제미나이'에게 결과지 해석을 의뢰했다. 분석 리포트를 함께 정독한 아내는 그제야 "이제야 당신이 왜 그랬는지 퍼즐이 완전히 맞춰진다"며 고개를 끄덕였다.</p>

<script>
(() => {
const initInteractive = () => {
const fadeEls = document.querySelectorAll('.sk-fade');
if (fadeEls.length) {
const fadeObserver = new IntersectionObserver((entries) => {
entries.forEach((entry) => {
if (entry.isIntersecting) {
entry.target.style.opacity = '1';
entry.target.style.transform = 'translateY(0)';
fadeObserver.unobserve(entry.target);
}
});
}, { threshold: 0.1 });
fadeEls.forEach((el) => {
if (el.dataset.skFadeInit) return;
el.dataset.skFadeInit = 'true';
el.style.opacity = '0';
el.style.transform = 'translateY(16px)';
el.style.transition = 'opacity 0.6s cubic-bezier(0.16, 1, 0.3, 1), transform 0.6s cubic-bezier(0.16, 1, 0.3, 1)';
fadeObserver.observe(el);
});
}
const barEls = document.querySelectorAll('.sk-bar');
if (barEls.length) {
const barObserver = new IntersectionObserver((entries) => {
entries.forEach((entry) => {
if (entry.isIntersecting) {
const targetWidth = entry.target.getAttribute('data-width') || '0%';
entry.target.style.transition = 'width 1.1s cubic-bezier(0.16, 1, 0.3, 1)';
requestAnimationFrame(() => {
entry.target.style.width = targetWidth;
});
barObserver.unobserve(entry.target);
}
});
}, { threshold: 0.15 });
barEls.forEach((bar) => {
if (bar.dataset.skBarInit) return;
bar.dataset.skBarInit = 'true';
barObserver.observe(bar);
});
}
const countEls = document.querySelectorAll('.sk-count');
if (countEls.length) {
const countObserver = new IntersectionObserver((entries) => {
entries.forEach((entry) => {
if (entry.isIntersecting) {
const el = entry.target;
const target = parseInt(el.getAttribute('data-target') || '0', 10);
const duration = 900;
const start = performance.now();
const step = (now) => {
const progress = Math.min((now - start) / duration, 1);
const eased = 1 - Math.pow(1 - progress, 3);
el.textContent = String(Math.round(target * eased));
if (progress < 1) {
requestAnimationFrame(step);
} else {
el.textContent = String(target);
}
};
requestAnimationFrame(step);
countObserver.unobserve(el);
}
});
}, { threshold: 0.2 });
countEls.forEach((el) => {
if (el.dataset.skCountInit) return;
el.dataset.skCountInit = 'true';
countObserver.observe(el);
});
}
const toggleBtns = document.querySelectorAll('.sk-q-toggle');
toggleBtns.forEach((btn) => {
if (btn.dataset.skToggleInit) return;
btn.dataset.skToggleInit = 'true';
btn.addEventListener('click', () => {
const body = btn.querySelector('.sk-q-body');
const icon = btn.querySelector('.sk-q-icon');
if (!body || !icon) return;
const isOpen = body.style.display === 'block';
body.style.display = isOpen ? 'none' : 'block';
btn.style.background = isOpen ? '#f2f7f6' : '#ffffff';
icon.textContent = isOpen ? '기준 보기' : '접기';
});
});
};
if (document.readyState === 'loading') {
document.addEventListener('DOMContentLoaded', initInteractive);
} else {
initInteractive();
}
document.addEventListener('astro:page-load', initInteractive);
})();
</script>
