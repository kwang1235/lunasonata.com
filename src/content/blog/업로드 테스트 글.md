# 🚀 자동 배포 시스템 테스트

이 글은 PC의 **VS Code**에서 작성되어 **Gitea**를 거쳐 **시놀로지 NAS**에서 자동으로 빌드 및 배포되었는지 확인하는 테스트용 문서입니다.

![대표이미지](https://image.lunasonata.com/2026/08/og-default.webp)

- - -

## 📌 자동화 체크리스트

1. **PC에서 글 작성** (`.md` 파일 생성)
2. **Git Commit & Push** (`git push origin main`)
3. **Gitea 저장소 전송 완료**
4. **시놀로지 작업 스케줄러 감지 및 빌드 (`npm run build`)**
5. **웹스테이션 최종 반영 확인**
