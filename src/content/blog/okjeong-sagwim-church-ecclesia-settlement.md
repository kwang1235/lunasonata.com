<p class="sk-p" style="margin: 0 0 20px; font-size: 1.02rem; color: #2c241e;">어느 교회나 그렇듯 등록을 하면 새신자 교육을 받게 된다. 우리 교회는 먼저 ‘풍삶초(풍성한 삶의 초대)’ 과정을 3주간 진행한다. 나는 ‘따름이’가 되었고, ‘이끄미’로는 현우 형제님이 배정되었다. 3주간의 교육을 받으며 현우 형제님이 속한 에클을 체험할 기회가 있었다. 근처 식당에서 점심을 먹고 교육관에서 모임을 가졌는데, 첫 만남이라 그런지 그저 어색어색하고 정신없이 시간이 흘렀던 기억이 난다.</p>
<p class="sk-p" style="margin: 0 0 20px; font-size: 1.02rem; color: #2c241e;">풍삶초 기간에는 에클 모임을 한 번밖에 경험하지 못한 채 수료를 하고 담임목사님과 면담을 가졌다. 목사님께서는 기존의 에클에서 다음 과정을 이어갈지, 아니면 다른 에클의 이끄미와 함께할지 물어보셨다. 기존 에클도 좋았지만 다른 곳의 분위기도 궁금했던 나는, 현우 형제님께는 조금 미안했지만 새로운 경험을 해보기로 결정했다.</p>
<p class="sk-p" style="margin: 0 0 20px; font-size: 1.02rem; color: #2c241e;">그렇게 두 번째 과정인 ‘풍삶첫(풍성한 삶의 첫걸음)’을 시작했다. 원래 5주 과정이지만 나는 1주를 더해 총 6주간 교육을 받았다. 이번 이끄미는 종길 형제님이었다.</p>
<p class="sk-p" style="margin: 0 0 24px; font-size: 1.02rem; color: #2c241e;">사실 현우 형제는 나보다 9살 어린 동생이었고, 종길 형제님은 나보다 14살이나 많은 형님이셨다. 평소 형님보다는 아우를 더 편하게 대하는 성격이라 처음에는 조금 어렵게 느껴지기도 했다. 하지만 시간이 지날수록 종길 형제님과 깊은 대화를 나누며 어느새 묵직한 친밀감이 쌓여갔다.</p>

entry.target.style.transform = 'translateY(0)';
observer.unobserve(entry.target);
}
});
}, { threshold: 0.1 });

});
}

const progressBars = document.querySelectorAll('.sk-progress-bar');

entries.forEach((entry) => {

barObserver.unobserve(entry.target);
}
});
}, { threshold: 0.2 });

progressBars.forEach((bar) => {
barObserver.observe(bar);
});
}
};

if (document.readyState === 'loading') {
